# R3 一次性真机回归清单（Mate 40 Pro / 鸿蒙 4.2 / API 31）

> 执行原则：全部功能一次连机走完；每项通过打勾；发现问题记 issue 修完复测。
> 前置：`adb install -r D:\smellmap-build\app\outputs\apk\debug\app-debug.apk`

## A. 主流程（PRD 用户故事逐条走）

- [ ] A1 打卡：长按地图 → 记录页 → 拍/选照片（看 EXIF 角标）→ 选口味 → 评分 → 保存 → 地图出现对应口味色**照片贴纸**
- [ ] A2 回顾：回顾页看到刚建的卡片；「换一批」变化；「再去一次」→ 日程页明天午餐出现
- [ ] A3 半夜找店：搜索页输入关键词命中；口味筛选生效；★N+ 筛选生效
- [ ] A4 详情：点贴纸信息窗 → 详情时间线完整（星级/口味/照片/修图角标）
- [ ] A5 导航：详情页「导航」拉起高德/百度/腾讯任一；全删地图 App 时复制店名兜底
- [ ] A6 外卖：「外卖」拉起美团且店名已进剪贴板
- [ ] A7 卡片：「做卡片」→ 预览正确（照片/口味色框/手写体/二维码）→ 分享出图
- [ ] A8 导入：设置→从美食卡片导入→选刚才的卡片截图 → 店进想吃清单
- [ ] A9 贴纸工坊：选图 → 四种风格切换 → 标签输入 → PNG 分享
- [ ] A10 备份恢复：导出 .tastemap → 卸载重装 → 导入 → 数据完整（含照片路径有效性）
- [ ] A11 日程提醒：日程项开提醒（授通知权限）→ 到点收通知
- [ ] A12 口味管理：新增自定义口味 → 记录页可选且颜色正确 → 删除
