# 味觉地图（TasteMap）隐私政策（草案，随商店提审定稿）

最后更新：2026-08-24

「味觉地图」是一款本地优先的个人美食记录工具。我们对你的数据承诺一句话：**你的数据只存在你的手机里，我们不收集、不上传。**

## 我们收集什么

不收集。本应用没有账号系统、没有自有服务器，任何功能都不要求你注册或提供身份信息。

## 数据存储

- 所有记录（店铺、打卡、照片、日程、想吃清单）存储在手机本地应用私有空间
- 照片经压缩后保存在应用私有目录，卸载应用即全部删除
- 备份文件（.tastemap）由你主动导出、由你自行保管；分享卡片只包含你主动生成的图片

## 权限用途

| 权限 | 用途 | 拒绝的影响 |
|------|------|-----------|
| 位置（仅前台） | 定位到当前位置展示地图 | 可手动移动地图，不影响记录功能 |
| 通知 | 美食日程到点提醒 | 不接收提醒，日程本身可用 |
| 照片/文件（系统选择器） | 选择照片生成贴纸与卡片 | 不能添加照片，其余功能正常 |

我们从不申请通讯录、短信、通话记录、后台定位等敏感权限。

## 第三方 SDK

应用内置高德地图 SDK（用于地图展示与定位）。地图瓦片加载与定位请求会与高德服务器通信，受高德开放平台《隐私权政策》约束（见 lbs.amap.com）。除高德 SDK 外，应用不含任何其他网络组件。

## 数据删除

卸载应用即删除全部本地数据。导出的备份文件请自行删除。
